# R4-05 — UI evidence

Date: 2026-11-09 UTC. **All race data and browser frames here are synthetic demo data
(`RUNAI_MODE=demo`). This is UI verification only, not live provider, H
session or checkout acceptance. No H frame was captured.**

## Method

Started `RUNAI_MODE=demo uv run uvicorn runai.app:app --port 8000`
(`/api/health` reported `live_ready: {linkup: false, h: false}`) and drove
headless Chromium with Python Playwright at 1440×900, 1024×768 and 390×844,
browser locale `en-US`:

1. Welcome: `h1` text read back as `YOU RUN. WE HANDLE THE REST.` (space fixed).
2. Typed `un marathon au printemps en Italie`; 150 ms after send (before the
   demo response) the thread showed `RUNAI · VOTRE COPILOTE`, FR pending copy
   and typing dots; after the reply `<html lang>` was `fr`.
3. Followed default suggestion pills to the plan card, confirmed, captured the
   demo agent stage (demo synthetic frames, badge `SYNTHÉTIQUE · démo`, never
   `EN DIRECT`) and the 3/3 ready banner.
4. Called the synthetic hooks `__runai.demo('running'|'stale'|'blocked'|'coverage'|'success')`
   (fake events flagged `synthetic`, example.com URLs, an SVG frame labelled
   "SYNTHETIC demo screen · not a real site"). These are visual fixtures; no
   provider was blocked or contacted.
5. At every state asserted `document.documentElement.scrollWidth > innerWidth`
   is `false` — it was false for all 18 checks (6 states × 3 widths).

Screenshots are attached to the PR body (not committed, to stay within ticket
scope). Known environment artefact: the headless VM has no colour-emoji font,
so country flags render as tofu boxes in the screenshots; real browsers show
the flag emoji.

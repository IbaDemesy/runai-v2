# R5-05 UI evidence — live-agent stage, end states, plan hero, race cards

Date: 2026-11-09. Mode checked in browser: `demo` (synthetic). Viewports: 1440×900,
1024×768, 390×844, FR locale. Screenshots were taken locally with Playwright for
review only and are not committed (no H/site frames were captured at any point).
No live H session was run for this ticket: the change is frontend-only and is
driven by the existing event contract (`step_progress`, `live_frame`,
`step_finished`).

## Before (round 4, docs/eval/round-4.md) → after

| Area | Before | After |
| --- | --- | --- |
| Frame badge | `EN DIRECT` on 60–190 s old frames | `EN DIRECT` only when frame age < 15 s, else `AGENT AU TRAVAIL`; frame age line (`image il y a 43 s`); demo/replay always `SYNTHÉTIQUE · …` |
| Frame change | hard swap | previous `<img>` kept as `.previous-frame`, crossfaded, then removed (animationend or 600 ms timeout) |
| Working feel | static cards | orange scan/pulse on card chrome (`.agent::before`), never over the frame; dark live header with mission recap and live counts (en action / prêts / relais) |
| Activity line | generic status | friendly `step_progress` line: `Étape N · Ouverture du site`, `Navigation sur le site`, `En attente d’un navigateur disponible` (queued) |
| Focus | none | `⤢` focus toggle: one agent enlarged, others as thumbnails; `Escape` closes, `←/→` cycle |
| Success | three cards | `3/3 · Tout est prêt avant paiement` banner with confetti dots + per-agent `Prêt — à vous de payer sur <domaine>` CTA (safe https, new tab) |
| Partial / blocked | wall of identical black `Reprenez la main` panels | one warm summary card (`x/3 prêts avant paiement` or `Vos agents vous passent le relais`), one friendly reason + next step per agent, `Continuer sur <site>` links; new `policy_denied` boundary copy; `blocked_url_host` never rendered |
| Plan origin | `ORIGIN —` | `Origine à choisir` chip-like placeholder |
| Prep pills | `Hôtel ✓ Transport ✓` next to `Inscription à vérifier` | ✓ only when date is official AND registration preparation is covered; unverified date → one coherent warning |
| Race cards | text lines | data tiles: date + countdown (`dans 150 j`), city · country (flag), distance; elevation / field size / price only when present |
| City names | `Geneva` in FR copy | FR/EN display names (Genève/Geneva, Milan, Lisbonne/Lisbon, Barcelone/Barcelona, La Haye/The Hague, …), UI copy only |
| Contrast | orange #fc4c02 behind white text | interactive fills use `--orange-strong` #d24000 (AA for white text) |

## Browser checks (demo, synthetic)

States rendered via the real chat flow (`un marathon au printemps en Italie` →
chips → plan → confirm) and `__runai.demo(...)`: welcome, pending/typing, race
proposals, plan, queued, running + crossfade, stale, focus, blocked, partial,
coverage, success.

- No horizontal overflow (`scrollWidth > innerWidth` false) in all 39 viewport/state combinations.
- No raw JSON / task text / `blocked_url_host` in `document.body.innerText` for any state.
- Suggestion chips render under the latest assistant turn; new questions appear below proposals.
- `prefers-reduced-motion: reduce` disables all animations/transitions.

Note: headless Chromium in the VM lacks a color-emoji font, so flags rendered as
letter boxes in local screenshots; real browsers render the regional-indicator flags.

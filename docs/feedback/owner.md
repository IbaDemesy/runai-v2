# Owner product feedback

- Beautiful, polished UX/UI is the #1 hackathon criterion. Design reference:
  Strava — bold athletic look, orange accent, clean cards, data-rich feel and
  great typography.
- The assistant must feel like ChatGPT: natural free-form conversation in French
  and English, streaming-like replies, chat bubbles and a bottom composer, plus
  clickable suggestion chips/cards. Users never need to know race dates or
  details: the assistant proposes a race with its sourced official date, origin,
  nights and budget. Accept these defaults in one click or change them by typing.
- One successful case means the assistant proposes the race, then three H agents
  (bib/registration, hotel and transport) run LIVE in parallel up to the
  pre-payment stop. The user sees all three working live on the page.
- Must work for any race, not just Milan.
- H API budget is not a constraint.

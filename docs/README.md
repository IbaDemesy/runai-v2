# Documentation map

This repository combines product and runtime references with internal engineering records.

## Repository root

- [README.md](../README.md) — visitor-facing product overview, features, setup and safety notes.
- [CONTRACTS.md](../CONTRACTS.md) — product API, runtime and safety contracts.
- [PLAN.md](../PLAN.md) — product journey, architecture, evaluation goals and current engineering priorities.
- [AGENTS.md](../AGENTS.md) — internal contributor and coding-agent rules.
- [HANDOFF.md](../HANDOFF.md) — internal integration status, verification evidence and next steps.

## Product and runtime references

- `site-policy.json` and `site-policy.d/` — runtime site-policy data used by the agents.
- `feedback/owner.md` — product requirements and owner decisions, retained as a feedback record.

## Internal development-process records

- `eval/` — round-by-round product evaluation notes.
- `evidence/` — implementation and verification evidence.
- `tickets/` — ticket specifications, ownership and file-scope records.
- `handoff/` — per-ticket implementation summaries, checks and follow-up work.

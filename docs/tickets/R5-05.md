# R5-05: P0 / design-first: Strava-grade 9/10 UI: live-agent stage that feels alive (honest step activity, frame crossfade, focus view), no bleak end states, coherent plan hero (no ORIGIN '—', no contradictory pills), queued/checkpoint/success states, data-rich race cards, FR city names, mobile polish

## Specification

Owner priority #1 is a beautiful Strava-inspired UI; round-4 design was 7/10 because live journeys end in dead-end chip loops or walls of blocked cards, 'EN DIRECT' sits on 60-190 s old frames, the plan hero shows ORIGIN '—' and 'Hotel ✓ Transport ✓' pills next to 'Registration to check'. Keep owner feedback (a)-(d): ChatGPT-style suggestion pills/cards under the latest assistant reply, chronological thread (new question below latest proposals), after launch keep the 3 agent cards and below them ONLY the agents acting live (no raw task/prompt/JSON/logs; one short friendly status line), immediate typing/progress feedback. 1) Live stage: per agent show the genuine latest frame with a smooth crossfade between frames, a subtle 'working' pulse/scan animation on the card chrome (never on/over the frame pretending to be footage), an honest activity line driven by step_progress ('Étape N', 'Ouverture du site', 'En attente d'un navigateur disponible' from R5-01) and the frame age ('image il y a 42 s'); badge reads EN DIRECT only when the frame is <15 s old, otherwise 'AGENT AU TRAVAIL'. Add a click-to-focus large viewer (one agent enlarged, others as thumbnails) and keyboard/escape support. Replay/demo stay labelled synthetic. 2) States: queued ('En attente d'un navigateur'), checkpoint reached/ready_for_payment success (celebration, 'Prêt — à vous de payer sur <domaine>' CTA, 3/3 banner), partial (x/3 ready with clear next steps), blocked: replace the wall of identical black 'Reprenez la main' panels with one consolidated, warm summary card listing each agent's friendly reason (16 reason codes, plus new 'policy_denied' copy for the beyond-boundary stop) and a 'Continuer sur <site>' link; never show blocked_url_host raw. 3) Plan hero/cards: never render '—' (show an 'origine à choisir' chip-like placeholder), pills only claim ✓ when P9 preparation says covered AND the date is official; unverified date shows a single coherent warning; race cards Strava-like data tiles (distance, date with countdown 'dans 147 j', city/country flag, elevation/field size/price ONLY when present in data, preparation badges); localize displayed city names FR/EN (Genève/Geneva, Milan, Lisbonne, Barcelone, La Haye) in UI copy only. 4) Polish: typography scale, spacing, motion (prefers-reduced-motion respected), skeletons for first reply, empty/error states, focus rings, contrast AA, responsive 1440/1024/390 with no overflow; dark live strip consistent with the orange accent. 5) Evidence: Playwright screenshots of demo/replay (synthetic, labelled) at 3 viewports committed under docs/evidence/ only as app-only/synthetic images if needed (no H/site frames); describe live checks in-session only.

## Spec
Implement owner feedback (a)–(d): ChatGPT/OpenAI-style suggestion pills/cards under the assistant reply; each new question BELOW the latest proposals in chronological order; retain three agent cards after launch, with only live screenshots below them and short friendly status lines; immediate streaming/typing/progress feedback. Never expose raw task, prompt, JSON or technical logs.

Deliver Strava-grade athletic design, energetic orange, strong typography, spacing, motion, accessible responsive layouts and intentional empty/loading/error states. Fix round-2 duplicate domain/unknown-access labels and awkward confirm ordering. P4 reason_code maps to a friendly FR/EN sentence plus next step, falling back to status when absent. Blocked cards must not keep "waiting for first capture".

Keep independent frames refreshing and the final screenshot through terminal pre-payment stops. No "suivi interrompu" while running. P6 localizes plan/agent cards with Mission.language, defaulting to browser/thread language when absent. Missing footage is unavailable, never simulated live.

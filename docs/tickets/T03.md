# T03 — Linkup official race search

## Goal
Implement read-only Linkup discovery from vague intent or a named race. Return
candidate races, editions, distances, official dates/registration links, source
URLs and retrieval time; feed T02's proposals instead of asking users for dates.
Verify frozen Milan dates; surface conflicts, no results, timeout and errors with
one useful follow-up, not guesses or silent travel-date substitutions.
Before parallel T04/T05/T06 start, define a stable shared adapter base/interface
in runai/adapters/__init__.py: async run, typed result, progress, public live-view/
frame hooks, safety stops and explicit errors. Add registry/wiring hooks in
providers.py for isolated registration.py, accor.py and trenitalia.py modules.
Missing modules must fail explicitly, not break startup via eager imports.
Document the interface in CONTRACTS.md; test it in tests/test_adapters_base.py.
T07 owns final integration once isolated adapters merge; no shared-file changes
are required from parallel adapters. Test empty/error/source-conflict paths.

start/end URLs, stop state and scrubbed public evidence, with explicit approval.

Update HANDOFF.md, then open one PR; merge only when CI is green.

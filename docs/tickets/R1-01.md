# R1-01 — Core: generic guided-mission API, dependency injection, background parallel agents, live frames, replay v2

## Goal
Integrate the isolated guide, Linkup discovery, H client and task builders into
a generic mission API with dependency injection and lazy optional imports.
Replace the bootstrap's fixed race path: a vague wish or named race leads to
sourced candidates and official dates, a guided turn and an editable plan.
Require explicit confirmation, then launch registration/hotel/transport together
in the background so polling can expose progress and genuine live frames while
they work. Preserve strict mode provenance and replay v2 with recorded frames;
missing keys/modules yield explicit 501 errors, never synthetic live success.
Update CONTRACTS.md to the actual implemented schemas/endpoints. Cover normal,
empty/error, missing modules/keys, repeated or absent confirmation, concurrency,
progress, replay and generic non-Milan journeys through injected offline fakes.
Coordinate component interfaces through handoffs; never edit their owned modules.
Document integrated live observations separately from offline test results.

## Guardrails
Follow [AGENTS.md](../../AGENTS.md), [PLAN.md](../../PLAN.md) and owner feedback.
Milan is one evaluation case, never a hard-coded path. No payment, booking,
accounts, terms/consent acceptance, medical declarations, form submission,
personal-data entry or captcha bypass. Cookie banners may only be dismissed
without accepting consent. Stop earlier than payment if any boundary appears.
Read keys from environment only; no secrets, tokens, private H URLs, emails or
other personal data in code, fixtures, logs or evidence. Never invent results
or live footage. Demo/replay must be visibly synthetic; missing live keys/modules
must fail explicitly, never fall back to fake success.


and record dated scrubbed observed evidence or an honest blocker in the PR.

One branch from latest main, one PR named with this ticket's id/title, no direct
main pushes. Merge only in the declared order and after green CI, resolving

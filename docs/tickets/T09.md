# T09 — Gladia voice input

## Goal
Implement isolated Gladia provider/export in runai/voice and a self-contained
static/voice.js module with start/stop/error/transcript callbacks. Ask microphone
permission, retain text fallback, and require transcript confirmation before agents.
No keys/audio/personal transcripts in logs. Test normal, empty audio, timeout,
missing-key/provider errors and permission callbacks where feasible offline.
Run alongside T03–T06: do not edit app.py, providers.py, models.py, shared HTML/JS/
CSS, CONTRACTS.md or HANDOFF.md. T08 wires endpoints and loads the voice module.
Write module/API integration instructions and checks in docs/handoff/T09.md.
One session = one branch = one PR; escalate scope/interface blockers.

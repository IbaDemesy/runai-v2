(5) Checkpoint semantics: a task may carry `checkpoint['prefill_patterns']` (pages where fields are typed, do NOT force_answer there) in addition to url_patterns (final pre-payment stop) and beyond_patterns. Without a profile, behaviour is exactly as today (stop at first personal-data page untouched). (6) StepResult gains optional `prefilled: bool` and `stop_label` (short friendly FR/EN-neutral string such as 'payment page reached'); never contains values.

Implement P3 coverage() with the pinned never-raises result.

Add reviewed exact-date hotel/transport adapters for Milan marathon (Apr 2027), Lisbon half (Mar 2027), Valencia 10K (Jan 2027), a Swiss summer trail and Freiburg half (Apr 2027). Cover default Paris, also Lyon/Bruxelles/Genève; never silently substitute a local origin. Prefer near-term editions for live acceptance where rail horizons are about 3–6 months, without inventing dates. Document site choices and actual stops. Registration fragment content belongs to R3-02.

## Common rules
Branch from current main; one ticket, one branch, one PR. Only allowed files;
request a scope amendment otherwise. Read [round-2 findings](../eval/round-2.md).
Import sibling interfaces lazily and fail closed when missing.

Never pay, book, create accounts, accept terms or consent, submit forms, enter
personal data or bypass captchas. Stop at the earliest boundary. Accor and
"prohibited" entries stay denied; unknown/expired reviews block before any H
session. Review actual terms first; prefer sites without captchas whose terms
allow agents and document choices. Live runs stop before payment.
H budget is not a constraint: run agents live in parallel whenever useful.

Write changes, pasted checks, dated scrubbed evidence, blockers and next steps
to `docs/handoff/R3-01.md`. Never publish secrets, private H URLs or personal
data; respect screenshot publication scope. Synthetic footage is labelled and
never proves live success.

## Specification

Round-4 failures to fix (live Linkup): (1) dead-end loops: Barcelona unverified card + only chip 'Try again' returned the identical card 10x; Portugal Funchal<->EDP unverified ping-pong 10x; Lyon 'En Suisse' chip returned the identical 'no race' reply 10x. Rule: no assistant turn may repeat the previous turn's message+candidates+chips; a retry must change the query (deeper depth, named-race query, neighbouring months, same country other city) and after one failed retry offer verified (official-date) alternatives or other concrete chips; static no-result chips ('En Suisse', 'En juillet', 'Un marathon') must actually re-search with that constraint merged into the intent. Unverified-date candidates are never the only recommendation when an official alternative exists. (2) Bare 'le marathon de Milan' / 'marathon de Milan' / 'Milano marathon' must find the same race as 'J'aimerais faire le marathon de Milan' (named-race intent + deterministic normalization + cache key); same for 'marathon de Berlin' after a mind change (A03). (3) Origin handling: at origin stage a bare city ('Paris') is the origin, never a race search (A08); 'non en fait de Bruxelles' / 'je pars de X' / 'départ de X' / 'from X' are origin corrections at ANY stage, never a destination (A16); an explicit origin inside the first request ('un 10 km aux Pays-Bas, départ de Bruxelles') sets origin and still searches the destination country. (4) Proposals: rank fully preparable+open (P9 registration covered/open and hotel+transport True from current origin) first; sold-out/closed editions never primary (label 'complet (liste d'attente)'); dedupe candidates by normalized name+date (Rome x2, Descobrimentos x2); when the user delegates or the top candidate is unpreparable, explicitly say what can be prepared. (5) Off-topic ('météo demain', poems) -> polite one-sentence refocus, never 'pas d'événement sourcé pour demain'. (6) Germany marathon search must surface sourced Berlin/Frankfurt/Hamburg editions when Linkup has them (country-level query templates incl. 'marathon Allemagne 2027 date officielle'); never invent. (7) Localize city/country names in turns/draft display to the conversation language (FR: Genève, Milan, Lisbonne, Barcelone, La Haye; EN: Geneva...) without changing the trip dict fields used by builders (keep canonical city for builders). (8) Keep first reply fast (p50 <= 10 s live) and the cache; keep P9 preparation display-only. Adversarial: extend tests/test_guide_adversarial.py to >=130 FR/EN rows adding A01-A16 of docs/eval/round-4.md as explicit regression rows plus loop-detection rows (same chip clicked 5x never yields identical turns), origin-correction rows, typo rows; each asserts reply, safe recovery, no sentinel PII stored, nothing launches without explicit confirm.

## Spec
Fix false-positive _UnsafeClaim verdicts: "No payment or booking was executed", "before any booking is confirmed" and URLs containing /book are not execution evidence. Real unsafe claims still fail closed. Map every terminal outcome to P4 reason_code. Stop quickly on no inventory, sold out or registration closed instead of exhausting steps.

Attempt a screenshot fetch every <=3 s while H runs, de-duplicated by image hash (P5). Retry once on session failure before progress, never after progress. Cap max_steps<=80 and each agent at a 10-minute wall clock, with remote cancellation. Preserve private screenshot-only runtime and the pre-run policy gate.

Models/providers add optional StepResult.reason_code; Mission.language copies the latest GuidedTurn.language (P6). Builder ValueError becomes blocked + no_site_coverage (policy_denied if its message says denied), with a friendly summary. Keep privacy, explicit confirmation, concurrent agents and honest results.

Publish R3 docs/queue and scope tests, deleting tests/test_r2_scope_contract.py. After R3-01..R3-04 merge, rebase and record >=5 UI-driven live cases in docs/eval/round-3-acceptance.md: Milan Apr 2027, Lisbon Mar 2027, Valencia Jan 2027, Swiss summer trail and Freiburg Apr 2027. Record assistant-proposed official dates, origins, overlapping agents, changing frames and genuine stop states. Prefer near-term editions for rail horizons (~3–6 months), never quietly substitute a named race. Target >=1 complete success, ideally Milan and Lisbon. Report all blockers honestly.

## Common rules
Branch from current main; one ticket, one branch, one PR. Only allowed files;
request a scope amendment otherwise. Read [round-2 findings](../eval/round-2.md).
Import sibling interfaces lazily and fail closed when missing.

Never pay, book, create accounts, accept terms or consent, submit forms, enter
personal data or bypass captchas. Stop at the earliest boundary. Accor and
"prohibited" entries stay denied; unknown/expired reviews block before any H
session. Review actual terms first; prefer sites without captchas whose terms
allow agents and document choices. Live runs stop before payment.
H budget is not a constraint: run agents live in parallel whenever useful.

Write changes, pasted checks, dated scrubbed evidence, blockers and next steps
to `docs/handoff/R3-05.md`. Never publish secrets, private H URLs or personal
data; respect screenshot publication scope. Synthetic footage is labelled and
never proves live success.

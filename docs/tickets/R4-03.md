## Common rules
Branch from current main; one ticket, one branch, one PR. Only allowed files;
request a scope amendment otherwise. Read [round-3 findings](../eval/round-3.md)
if present. Import sibling interfaces lazily and fail closed when missing.

personal data or bypass captchas. Stop at the earliest boundary. Accor and
"prohibited" entries stay denied; unknown/expired reviews block before any H
session. Review actual terms first; prefer sites without captchas whose terms
allow agents and document choices. Live runs stop before payment.

to `docs/handoff/R4-03.md`. Never publish secrets, private H URLs or personal

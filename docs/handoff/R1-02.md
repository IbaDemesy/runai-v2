# R1-02 — H Company agent client

## Changes

- Add isolated `HAgentRunner.run(task, on_event)` against the official H v2 API;
  no imports from sibling modules in the agents package initializer.
- Emit scrubbed step progress, documented public share URLs and screenshot
  bytes; ignore private live-view/session URLs and raw reasoning.
- Compose pre-payment/pre-consent/pre-form guardrails and structured JSON output;
  validate public HTTPS handoffs, reject execution claims, cap time/steps and
  cancel known remote sessions on timeout/cancellation/errors.
- Add URL/text scrubbing and offline MockTransport regression coverage including
  independent parallel runs. No provider calls in the test suite.

## Evidence and limitations

- See `docs/evidence/h-client.md` for official endpoints, site policy review,
  dated real smoke observations and precise safety limitations.
- Final smoke: `blocked` after 115.48 seconds on the official Lisbon half-marathon
  information page; **10 real PNG frames**, public-share event and 12 progress
  events. No form opened; dynamic CTA could not be verified safely. Three runs
  total; no claimed pre-payment success.
- The live smoke exposed H's terminal-drain HTTP 204 behavior; fixed retaining
  terminal state rather than timing out and covered with an offline regression.
- H hosted tools cannot be intercepted. This is prompt/cap/cancel/answer
  validation, **not** a deterministic tool-level pre-consent barrier.
- Screenshot pixels are not OCR-redacted; only anonymous public pages are
  supported. No private session/resource/share URLs are committed as evidence.
- Runtime `httpx` dependency is outside this ticket's file scope; lead delegated
  that change to the pyproject owner. Main currently installs it as a dev dep.

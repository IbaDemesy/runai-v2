  one adult without reduction/Half-Fare, selected outbound and return on exact
  dates, stop at fare/ticket summary before passenger/login/payment. No form
  submission or personal data; no return/party URL parameters are claimed.

  and `trip=` preview URLs. NS existing guess retained; defensive beyond patterns
  merged, also for legacy CP/Vueling alternatives. Ready patterns exclude unsafe
  nested/state URLs. Benign guest/pax query keys remain safe. Evidence docs supersede older
  coverage claims without claiming READY or new provider authorization.
- Offline tests cover eval routes, verified ordering/fallback-only behavior,
  strict dates, expiry/denial, SBB URL escaping/instructions, P11 and P12 safety.
  Gateway mechanics use an explicitly synthetic registry where production
  gateway render evidence is absent.

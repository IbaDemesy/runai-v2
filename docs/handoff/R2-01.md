## Pinned additive contract consumed

- POST /api/missions and /messages accept JSON background:true, return 202
  discovering; GET mission provides final guiding/ready turns or Mission.error.
  Failure retains existing turns; POST /messages retries the same mission.
- Registration_access is optional null/object with account_required, captcha,
  source, observed_at, note. Only known booleans produce curated warnings; note
  is not inserted as arbitrary provider text. Unknown is never login-free.
- Existing synchronous main remains supported through additive-field 422
  fallback. No API/core/model/CONTRACTS changes are included in this PR.
- Only live_frame frame_id is used; provider live_view_url is entirely ignored.
  Each /api/frames image is decoded before insertion. Results retain final view.

## Evidence, decisions and blockers

No network calls, browser interactions or live H runs. Every external site-flow
claim is marked assumed. UI/site behavior is visually unverified. No inventory,
fare, checkout access or authorization is claimed. Budget is a total hint with
currency supplied by the caller, not a computed agent allocation. Countries use
English names or ISO two-letter codes; unsupported origin inference uses flights.
Missing hotel budget requires human clarification before rate selection.

Strict no-form-submission instructions take priority over completing search;
sites requiring search submission must produce a blocker. Allowlisting does not
imply permission to automate. No outstanding coding blockers.

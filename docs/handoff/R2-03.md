## Pinned interface decisions

Uses only lazy `runai.agents.site_policy.evaluate_url(url, kind)`; no alternate
module fallback. Pinned mapping keys are supported directly (attribute-style
results also accepted). A valid identifier, nonexpired ISO date (or null for no expiry), explicit
screenshot scope and matching reviewed host are mandatory. Task `allowed_hosts`
intersects policy hosts. Actual start/fallback URLs are evaluated; every planned
host must already belong to returned reviewed scope (no synthetic root calls);
optional policy path prefixes constrain navigation, otherwise the pinned review
is host-wide. `expected` enters the prompt; only kind-relevant keys enter the
schema/comparison. Dates, numeric distances/party sizes and accent/case-insensitive
names are normalized. Observation checks only inspect URL paths/queries and
titles, never page markdown/nav text; checkout alone does not cancel a frame.
Baseline builders without expected verification cannot claim ready.

No public schema or runner signature change. No core/sibling file edits.
Prompt/post-observation checks are NOT a per-action firewall. Final screenshot
inspection by a human is necessary: self-reported extracted fields are not
independent proof. Frames are not OCR-redacted; authenticated/personal pages
are prohibited and suspected sensitive observations are suppressed/cancelled.

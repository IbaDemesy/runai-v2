# R1-01 — generic guided-mission core

## Changes
- Removed frozen Framing/TARGET and `/reply`. Guided text/chip turns, explicit
  ready/confirm transitions and mode-specific lazy dependency injection.
- Confirmation returns 202 before three concurrent background workers finish.
  Ordered progress/live-view/frame events and MIME-aware frame retrieval.
- Strict result/payment guardrails; blocked/failed isolation and partial status.
- Three labelled demo SVG frames per kind; replay v2 with original timestamps
  and visible three-step failures on missing/invalid trace files.
- Lazy H task builder/client integration and documented Trip/HTTP contracts.
- Ready plans prefer `engine.trip_payload(state)`; deep Linkup discovery uses
  120 seconds and translates guide season/named-race hints.
- Review hardening: public-only URL validators at event/result boundaries,
  documented regional H share routes only, oldest-first frame retention capped
  at 256 frames / 32 MiB, and selected-race manual replay registration links.
- Only ticket-owned repository files changed. Frontend implementation is R1-07.

## Live site-policy blocker (2026-11-08)
Reviewed [Accor legal conditions](https://all.accor.com/a/en/information/legal-conditions.html):
personal/private/non-commercial viewing has a limited exception, but public
redistribution and repeated extraction are restricted. The H client creates a
key-free public share for every task, so omitting footage from Git is not enough.
**Do not run the current default Accor task.** Hilton's alternate
[site-usage agreement](https://www.hilton.com/en/p/site-usage-agreement/) also
restricts copying/scraping/republication; it is not an established safe substitute.
No hotel or transport H session was started.

Lead explicitly approved keeping R1-01 in scope, verifying registration only
when dependencies are available, and deferring policy-aware site selection /
public-share opt-out to the next round. No full live pre-payment claim is made.

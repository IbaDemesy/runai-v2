# R1-05 handoff: registration agent task builder

## Changes
- `runai/agents/registration.py`: `build_task(trip) -> dict` (kind, site_name, start_url,
  instructions, stop_before, success_signal, fallback_url, max_steps). Uses `registration_url`,
  else `official_url`; raises `ValueError` if race or both URLs missing or any URL is not https.
  Instructions are generic (official link -> officially linked platform such as Njuko, Active,
  Race Result, Ahotu, RPM Sports, ticketing), select distance without personal data, stop at
  personal data / login / medical certificate / consent / payment / captcha / submission,
  report BLOCKED for closed / sold out / not yet open / lottery. No traveler data in the prompt.
  Standalone: no imports from other new modules.
- `tests/test_agent_registration.py`: normal, fallback, missing/invalid URLs, stop rules and
  no personal data, generic across Milano / Berlin / Barcelona.
- `docs/evidence/registration.md`: observed vs assumed paths for 3+ races.

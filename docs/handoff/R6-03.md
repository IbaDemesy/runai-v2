# R6-03 handoff — registration coverage, Stoos checkpoint, sold-out detection

## Changes
- `runai/agents/registration.py`
  - `availability_from_evidence(text, url)`: waiting-list/sold-out (waiting list, lista de
    espera, Warteliste, liste d'attente, wachtlijst, sold out, ausverkauft, complet, esgotado,
    agotado, uitverkocht) -> `sold_out`; closed -> `closed`; will open / startet
    voraussichtlich / coming soon -> `not_open`; explicit register-now/abertas -> `open`;
    else `unknown`. Never raises.
  - `build_task`: a waiting-list/sold-out/closed start URL puts AVAILABILITY FIRST
    `BLOCKED sold_out|registration_closed` first; new step 5b tells the agent never to join a
    waiting list and to answer only that registration is unavailable (offline: such an
    answer maps to `sold_out` via `hclient._blocked_reason`, not a payment claim).
  - `registration_coverage` (P8, additive keys): `registration` in the P9 vocabulary
    (`covered` only for fresh open, else `sold_out|not_open|closed|unknown|prohibited|
    uncovered`) and `preparable_open: bool`. A waiting-list/closed/not-open sourced
    `registration_url` downgrades the status. Fails closed (`covered=false`) when the start
    URL is not scrub-clean or `runai.agents.scrub` is missing. max_steps 60, distance
    tolerance 0.15 km and fail-closed malformed checkpoints unchanged.
- `docs/site-policy.d/registration.json`
  - `stoos-trail-raceresult`: checkpoint enabled on the observed participant form
    `^/422182/registration?…regname=` (bare landing does not match); availability open
    2026-11-09 incl. ST10/ST24/ST46 contest labels.
  - New `frankfurt-marathon-de` (Njuko white-label `in.motionevents-registrations.com`, event
    path only), Njuko `form_individual-form` checkpoint, availability open 2026-11-09.
- `tests/test_agent_registration.py`: Stoos checkpoint/landing tests (replaces the old
  "Stoos shell is not a checkpoint" test), per-country fresh-open coverage, evidence-text
  matrix, waiting-list URL -> sold_out first, Berlin/Paris/Lyon/Valencia 10K/Barcelona/
  Irontrail still denied, Frankfurt not preparable while unscrubbable, scrub-missing fail
  closed, `registration`/`preparable_open` keys, checkpoint never matches the landing page.
- `docs/evidence/registration.md`: dated R6-03 read-only observations and live status.

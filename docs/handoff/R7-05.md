# R7-05 handoff — P0 design polish (runner profile, honest launch, prefilled end states)

Date: 2026-11-09. Files touched: `static/app.js`, `static/styles.css`, `tests/test_static_ui.py`, `docs/handoff/R7-05.md` (no `static/index.html` change was needed).

## Changes
- **Runner profile card (P14)** in the plan stage, shown once per mission just above the confirm CTA: name, email, phone, birth date, gender, nationality, optional address; privacy note ("Gardé en mémoire pour cette mission uniquement, saisi par les agents dans les formulaires, jamais enregistré"); "Remplir avec un profil de test" (fake Test Runner identity), "Continuer sans profil", "Enregistrer pour cette mission".
  - Submit = `POST /api/missions/{id}/profile` with a JSON body (never a URL/query, no `<form>` GET). Inputs are cleared after success/404/501/skip.
  - Success renders only known `profile_status` field names with ✓ (labels come from the client; server values are never rendered).
  - `404`/`501` → card removed and never shown again for the mission; other errors → inline retry copy without values.
  - No `console`, `localStorage`, `sessionStorage`, `history` or cookie usage (static test asserts it; DOM test spies on all of them).
  - Card is moved (not duplicated) when the plan is edited; it is removed if still open at launch.
- **Honest coverage before confirmation**: kinds whose `race.preparation` is uncovered/closed/sold-out/not-open are shown dashed "non couvert · à faire vous-même" in the plan crew, with a coverage line ("2 agents prêts à partir · Transport : pas encore de site couvert…") and a matching CTA ("Confirmer et lancer les 2 agents disponibles ↗" / "…les 3 agents ↗" / one / zero variants).
- **Launch never looks broken**: before the first frame each card shows a shimmer browser skeleton, "Connexion au site…" and a big real elapsed counter ("7 s écoulées", updated by each poll). Agents known as uncovered show a calm hatched "Pas de site couvert pour ce trajet · Détails dans le bilan" panel. "Aucun site ouvert" is gone (replaced by "Pas de site couvert pour ce trajet" / "Reprise sur le site officiel").
- **"Essai d’un autre site"**: animated pill over the frame + hopping skeleton (`data-alternative`), cleared on terminal states.
- **Advanced-as-far-as-possible end states**: `prefilled: true` (or `status: "prefilled"`, normalised to `ready_for_payment`) + `stop_label` render "Formulaire pré-rempli · prêt à payer", the sanitised stop label, a 4-step milestone bar (Site · Sélection · Coordonnées · Paiement · vous, only when `prefilled`) and a "Continuer sur <site> ↗" handoff. Plain ready keeps "Prêt avant paiement".
- **Copy**: composer placeholder follows the stage (welcome → candidates "Choisissez une course ou précisez votre envie…" → plan "Modifier le plan… (ex. départ de Lyon, 3 nuits)"); generic ready question ("Ça te va comme point de départ ?") becomes "Tout est bon ? Lancez les agents, ou modifiez un détail ci-dessous."
- **Synthetic labelling**: the `[Synthétique / Synthetic]` prefix is stripped from every rendered string (chips, cards, recap); choose-race chips get a small "Synthétique" badge driven by mission mode (none in live).
- **Bilan above the fold**: when finished, the stage becomes a flex column with a compact heading, then banner/summary, then cards (verified at 1440×900).
- Mobile 390px: profile grid 2 columns with full-width text fields, stacked actions (primary first), 16px inputs (no iOS zoom), placeholder ellipsis. Reduced motion still disables all animations.

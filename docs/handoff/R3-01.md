### Verified causal chain and alternative check

1. The diagnostic ran the real `HAgentRunner.run` for the ordinary transport builder's
   task. The wrapper was invoked directly from its `observation_event` branch and
   observed raw metadata URL `about:blank`; the actual `_reviewed` result was false.
2. `scrub.scrub_url` rejects non-HTTP(S) schemes, so the runner's `clean_url` turns that
   URL into `None`. `hclient._reviewed` rejects it rather than considering it a reviewed
   public HTTPS URL. A separate local assertion check reproduced both results.
3. In `HAgentRunner.run`, `if not _reviewed(observed, reviews) or ...` therefore raises
   `_PolicyBlocked` **before** assigning `final_url`, emitting reviewed-page progress or
   fetching a frame. This short-circuits the other two clauses. Diagnostic evaluation
   of those predicates showed neither the forbidden pattern nor title cleaning would
   independently block this observation.
4. The `except _PolicyBlocked` handler returns the observed generic policy-denied reason.
   The real output's single start event and zero frames agree with this dispatch path.
5. To try to disprove a missing provider-scope explanation, local checks also passed the
   unchanged task through `hclient._policy` and asserted `_reviewed(task['start_url'],
   reviews)` is true. The existing Vueling start URL is already reviewed. Adding a host
   or changing adapter selection cannot authorize the observed `about:blank` page.

This confirms **this diagnostic session's** cause. STEP 5 did not retain observation
metadata, so the same cause for its earlier transport denial remains unverified.

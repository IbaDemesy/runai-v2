# R3-04 — guide robustness

## Changes

- `runai/guide/parse.py`: per-message FR/EN cue counts (`Intent.fr_cues`,
  `Intent.en_cues`); `country_name()` canonicalises English/French/local names
  and ISO2 codes (Espagne/España/ES → Spain); typo/emoji normalisation
  (semiii, espagnee, spainn, maraton, traill, suise…).
- `runai/guide/types.py` (additive): `Suggestion.kind` gains `"distance"`,
  optional `Suggestion.group`; `GuidedTurn.language: "fr"|"en"|None` (P6).
- `runai/guide/engine.py`:
  - empty first discovery → exactly one broadened sourced retry (month window
    dropped, `broaden=True` hint for close distance variants) before "no race";
    broadened results are never auto-selected.
  - race without numeric distance → distance question whose primary chips are
    all `kind="distance"`: sourced values from the race's own `distance_label`,
    else 5/10/21.1/42.195 km with `provenance="suggested_default"`; other races
    only after them in group "Autres courses"/"Other races". Ready still
    requires a numeric distance.
  - unknown registration access is not shown (no " — accès inconnu" /
    " — access unknown"); blocked access keeps the human-handoff warning.
  - source provenance de-duplicated by domain.
  - language detected per typed message with sticky fallback (FR after an EN
    refusal → FR reply and vice versa); every turn carries `language`.
  - origin chips ordered by lazy `runai.agents.site_policy.coverage("transport",
    country, city, origin_city, today)` (P3) when present; missing function,
    exception or no covered city → previous order Paris/Lyon/Bruxelles/Genève.
    Copy never mentions coverage.
  - all automatically applied defaults listed in one sentence
    ("Valeurs par défaut proposées, modifiables : départ de X, 2 nuits et
    budget de 450 €.").
  - explicit refusals for skip-confirmation requests and forbidden sites
    (Booking, Accor); no launch without `/confirm`.
- `runai/discovery/linkup.py`: country code + local-language distance synonyms
  in the query; `broaden` hint widens the window/distance; per-row validation
  (malformed rows dropped, malformed envelope still raises
  `DiscoveryResponseError`); edition year from sourced dates; near-term
  official editions first; `official_url` kept only when its host matches a
  source; `registration_url` kept only when sourced from the official page
  (explicit `registration_source_url` on the official host, or URL present in
  the cited sources on the official/linked host); no query-string session URLs;
  never fabricated. Untrusted-data handling unchanged.

## Blockers / limits

- `site_policy.coverage` (P3, R3-01) was not on main at implementation time;
  ordering is tested with an injected module and falls back to the default
  list in production until R3-01 merges.
- The live smoke did not need the broadened retry (first query non-empty);
  the broadened path is verified by fixtures only.
- Sourced registration URLs are links, not proof of open registration,
  authorization or captcha/account absence.
- Live Linkup latency (~48 s) remains; R3-05/UI own loading feedback.

## Review fixes

- Delegated choice ("choisis pour moi … en juillet") never auto-selects a
  broadened race outside the requested months; candidates are shown instead.
- "oui"/"yes" accepts the distance chip when it is the only one suggested
  (never picks among the four standard distances).
- Linkup lists dated sources first, so per-domain de-duplication keeps the
  dated announcement rather than an undated homepage on the same host.

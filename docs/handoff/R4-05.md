# R4-05 handoff — Strava-grade UI polish

## Changes (static UI only)
- `static/index.html`: richer agent cards (site line, progress stepper, stage
  with overlay badge), `#mission-banner`, `#coverage`, theme colour `#fc4c02`.
- `static/styles.css`: rewritten light Strava-style system (orange `#FC4C02`,
  condensed display type, cards, ChatGPT-style suggestion pills, route line,
  plan tiles, stepper, stale shimmer, success pop, coverage card), responsive
  1440/1024/390, focus-visible, `prefers-reduced-motion`.
- `static/app.js`:
  - `translate()` keeps surrounding whitespace (fixes `HANDLETHE`); `<html lang>`
    follows conversation language; FR/EN detection from typed text at send time.
  - Fresh frame badge `EN DIRECT`/`LIVE` only in live mode and < 15 s
    (`FRESH_MS`); otherwise `L’agent travaille · image il y a N s` + shimmer over
    the last real frame; demo/replay labelled `SYNTHÉTIQUE`.
  - Per-agent stepper Démarrage → Sur le site → Sélection → Prêt avant paiement
    / Bloqué, elapsed timer, site domain, `Essai d’un autre site`.
  - All 16 `reason_code`s → specific FR/EN sentence + next step; never-started
    agents show `Non démarré`.
  - All three blocked before activity → one consolidated coverage card with
    change chips sent as normal guide messages.
  - `ready_for_payment` → sober success box and CTA `Prêt — à vous de payer sur
    <site>` (safeURL-validated, new tab), dates/party/total when present;
    mission banner `Tout est prêt avant paiement` at 3/3.
  - Race cards: big distance, date + countdown, flag, source domain, preparation
    badges only when `RaceOption.preparation` exists; elevation/field size only
    if present. Plan card route origin → city, tiles, the 3 agents and targets.
  - Synthetic test hooks `__runai.demo(...)`, never labelled live.
- `tests/test_static_ui.py`: harness updated; new scenarios `welcome`,
  `fr-detect`, `fresh`, `never-started`, `coverage`, `success`, `preparation`;
  reason-code test checks 16 distinct sentences + next steps.

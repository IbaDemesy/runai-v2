# R2-05 handoff

## Changes
- Core: opt-in background discovery (`background:true` -> 202 `discovering`),
  truthful `discovery_progress` heartbeats, `discovery_failed`, retryable
  failures, generation guard against stale results, and 409 for messages and
  confirm while discovering.
- Privacy: input redaction (contact details, keys, card numbers, IBAN) before
  the guide, state or events see it. Public output is sanitized again
  recursively, and 422 bodies contain no input.
- Confirmation gate: the race date must be future and official in live, the
  trip must be consistent, and the race provenance must match the mode.
- Providers: Accor/Omio fallbacks removed; observed blocked/failed handoffs are
  kept and never upgraded.
- Docs: owner feedback, R2 queue/tickets, AGENTS/PLAN/HANDOFF/README, pinned
  interfaces in CONTRACTS.md, queue validator `tests/test_r2_scope_contract.py`.

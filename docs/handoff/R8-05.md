# R8-05 · Static UI

## Changes
- `static/app.js`: profile uses `address_line` for manual and fake-profile entry;
  422 locations map to safe localized field messages without echoing API values.
  Existing 404/501 hiding and memory-only handling remain.
- Frame badges distinguish live (<15 s), recent (15–60 s), and frozen (60 s+ or
  explicit `stale_frame: true`); null leaves age-based behavior unchanged.
  A recurring timer ages frames without polling. Frozen frames use a muted badge
  and a thinking status, not claims of live work.
- Run footers retain the public site host. Calm distinct preflight reasons have
  handoff links; not-yet-bookable links invite viewing timetables.
- Every terminal agent has an activity Bilan with five milestones and an orange
  READY continuation. Prefill is never marked without `prefilled`; public handoff
  URLs alone never prove a site opened. No-run preflight results complete no
  milestones. Demo hooks include `preflight`, `running`, `stale`, and `success`.
- Month pills localize ISO months; latest-reply chip behavior is preserved.
- `static/styles.css`: activity rhythm, calm preflight tone, reduced-motion-aware
  card entrance and visible blocked-agent handoffs/Bilan after completion.
- `tests/test_static_ui.py`: existing executable Node DOM harness, updated age/
  profile/READY expectations plus 422, preflight, frozen flag and FR/EN month cases.
- `static/index.html` did not need changes.

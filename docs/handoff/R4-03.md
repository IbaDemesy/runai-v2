- `runai/agents/registration.py`
  - P8 `registration_coverage(race, *, today=None, registry=None) -> {covered, status,
    policy_id, observed_at, prohibited}`: pure/offline, never raises; `covered` = `build_task`
    would succeed (synthetic stay around `race_date`); `status` = matched adapter

## Checks

their required platforms are prohibited and navigation cannot be safely gated mid-run.
Both sourced URLs are checked for a prohibition before selecting an adapter/start URL;
an allowed sourced platform cannot bypass a prohibited official organizer. Regression
coverage includes the real registration URL, missing/empty URL and an allowed Njuko URL.

Distance-scoping fix: optional `availability.distances_km` is a nonempty list of positive,
finite numeric distances; malformed/empty values fail closed. An unmatched race distance
gets unknown status with no observation date and no AVAILABILITY FIRST instruction, but
keeps normal reviewed adapter coverage. CPC scopes its sold_out record to 21/21.0975/21.1
km; 5/10 km remain covered, status unknown. Tests cover both distances and invalid scopes.
